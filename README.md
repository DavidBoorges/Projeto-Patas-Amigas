# 🐾 Projeto Patas Amigas

Uma plataforma web desenvolvida para apoiar a ONG Patas Amigas na gestão de adoções, arrecadação de doações e cadastro de voluntários, facilitando o resgate e o cuidado com animais vulneráveis.

---

## 🎯 Objetivo do Projeto

Conectar a comunidade com a ONG através de uma interface acessível e intuitiva. O projeto resolve a dificuldade de centralizar informações sobre os animais resgatados e simplifica os processos de doação e engajamento comunitário.

A plataforma permite que os usuários:
* **Conheçam os animais disponíveis:** Naveguem pelas opções de adoção e saibam a história de cada pet.
* **Façam doações:** Encontrem formas práticas de apoiar financeiramente ou com recursos.
* **Cadastrem-se como voluntários:** Preencham formulários para ajudar nos cuidados e eventos.
* **Acompanhem os projetos:** Vejam as iniciativas ativas realizadas pela organização.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação de todas as páginas (`index.html`, `cadastro.html`, `doacao.html`, `projetos.html`)
* **CSS3:** Estilização, layout responsivo e identidade visual
* **JavaScript:** Interatividade nos formulários e navegação
* **Git & GitHub:** Versionamento e hospedagem do código-fonte

---

## 📌 Páginas da Plataforma

- [x] **Página Inicial (`index.html`):** Apresentação da ONG e chamada para ação.
- [x] **Cadastro de Voluntários (`cadastro.html`):** Formulário para novos ajudantes.
- [x] **Gestão de Doações (`doacao.html`):** Meios de apoio e contribuição.
- [x] **Projetos da ONG (`projetos.html`):** Informações sobre eventos e resgates.
